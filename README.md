# Finance-Me

**Finance-Me** — современное Android-приложение для персонального финансового учета, структурирования расходов и контроля месячного бюджета, разработанное на Kotlin с использованием декларативного UI-фреймворка Jetpack Compose и интеграцией алгоритмов искусственного интеллекта.

---

## 1. Концепция и назначение

* **Основная цель:** Обеспечить удобный и быстрый учет ежедневных финансовых транзакций, наглядный мониторинг текущего баланса и жесткий контроль лимитов расходов.
* **Базовые принципы:**
  * Минималистичный дизайн без визуального шума.
  * Высокая скорость ввода операций (добавление транзакции в одно действие через панель «Quick Add»).
  * Наглядность финансовой аналитики благодаря кастомным круговым диаграммам (Donut Charts) с разбивкой по категориям.
* **Контроль лимитов:** Автоматический расчет доступного остатка средств и своевременное информирование пользователя при преодолении порогов в 80% и 100% от установленного месячного бюджета.

---

## 2. Технологический стек

Архитектура приложения построена в соответствии с современными стандартами Android-разработки (Clean Architecture / MVI/MVVM):

| Компонент | Технология / Библиотека | Описание |
| :--- | :--- | :--- |
| **Платформа и Язык** | Android (SDK 36) + Kotlin | Реактивное программирование на базе Kotlin Coroutines и StateFlow для безопасной работы с состоянием. |
| **Пользовательский интерфейс (UI)** | Jetpack Compose + Material 3 | Декларативная верстка, анимации переходов (`animateContentSize`), векторный рендеринг графиков через `Canvas` и тактильный отклик (`Haptic Feedback`). |
| **Локальная база данных** | Room Database (Room KTX) | Надежное персистентное хранение транзакций, пользовательских категорий и настроек бюджета с асинхронным доступом через DAO. |
| **Сетевой слой и Валюты** | Retrofit 2 + OkHttp + Moshi | Получение курсов валют в реальном времени через `CurrencyService` (API open.er-api.com). Поддержка конвертации: UAH, USD, EUR, PLN, GBP, CZK. |
| **Интеллектуальный анализ (AI)** | Firebase AI / Gemini API | Автоматический анализ финансового поведения и генерация персональных рекомендаций по оптимизации трат. |
| **Локализация и Оформление** | Multi-Language & Themes | Встроенная поддержка трех языков (украинский, английский, русский) и трех режимов тем (системная, светлая, темная), включая палитру Mulberry Mint. |

---

## 3. Ключевые возможности

* **Экран «Сводка» (Summary):**
  * Верхняя панель метрик: текущий общий баланс, суммарные расходы за период и оставшийся лимит.
  * Интерактивная диаграмма распределения трат по категориям с цветовой дифференциацией.
* **Быстрый ввод («Quick Add»):** Сетка шаблонных кнопок для мгновенного логирования регулярных трат (Продукты, Транспорт, Аренда, Кофе, Кино).
* **Категоризация и Поиск:**
  * Предустановленная сегментация: Еда, Транспорт, Жилье, Развлечения, Коммунальные услуги, Другое.
  * Встроенная поисковая строка с мгновенной фильтрацией списка транзакций по названию и сумме.
* **Система предупреждений о лимитах:** Динамическое изменение визуальных акцентов интерфейса и вывод триггерных предупреждений (`warningLimit`) при исчерпании 80% и 100% месячного бюджета.
* **Шеринг отчетов («Share Report»):** Быстрая генерация форматированной текстовой сводки финансового состояния за выбранный период для отправки через системное меню «Поделиться».
